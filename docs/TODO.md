## 已否决

### 剔掉涉及词表外字的 CSC 训练样本

原设想:错字位置有 3.69% 涉及词表外字,这部分训练信号是错的,剔掉可能涨点。

2026-07-26 拆开量了一遍,前提不成立。按错字和正字分别是否在词表内分:

| | 位置数 | 占错字位置 |
|---|---|---|
| 都在词表内 | 336,395 | 96.31% |
| 只有**错字** OOV(目标可学) | 12,330 | 3.53% |
| 只有**正字** OOV(目标不可学) | 524 | 0.15% |
| 两者都 OOV | 42 | 0.01% |

3.69% 里的绝大多数(3.53%)是「错字模糊但正字在词表内」,例如 錓→康、
茌→在。这类目标完全可学,属于困难样本而不是错误标注,剔掉等于丢掉有效信号。
真正学不了的只有 566 个位置,占错字位置 **0.16%**。

测试集上空间更小:SIGHAN-15 的 556 个错字位置里,因正字不在词表而注定纠不对
的只有 1 处,**F1 上限损失 0.0014**。CSC 单轮训练波动实测 ±0.02,效应比噪声
小一个量级,单次实验测不出来。

结论写进了 [`WHY.md`](WHY.md#字级词表覆盖不了所有汉字)。

将来若要验,最干净的做法是只屏蔽正字 OOV 的那 566 个位置:`cor_loss` 本来就
用 `ignore_index=-100`,在 `prepare/build_csc.py` 的 `encode_pairs` 里把这些
位置的 `cor_labels` 写成 -100 即可,不必动 `src/`。
